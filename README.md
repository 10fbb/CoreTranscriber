# ТехСтенограмма для Windows

Локальное приложение для записи встреч и транскрибации без платного API.

Что умеет:

- отдельно записывает микрофон и звук Windows-приложений;
- получает звук Dion, Express, Discord, Zoom и других программ через WASAPI loopback;
- распознаёт речь локально моделью Whisper;
- помечает микрофон как «Вы»;
- различает удалённых участников по голосовым отпечаткам;
- позволяет переименовать «Собеседник 1» в реальное имя или роль;
- использует словарь технических терминов;
- поставляется с тематическими TXT-словарями, включая эквайринг и банковский процессинг;
- позволяет выбирать один, несколько или все словари для встречи;
- позволяет создавать, изменять и удалять собственные словари;
- позволяет заранее скачать и подготовить выбранную модель Whisper;
- показывает реальную дату и время начала каждой реплики;
- позволяет отдельно исправить роль и текст любой строки стенограммы;
- сохраняет WAV, TXT, Markdown, JSON, SRT и DOCX.

## Быстрый запуск на Windows 10/11

1. Установите Python 3.11 с сайта python.org. При установке включите **Add Python to PATH**.
2. Распакуйте проект в папку без кириллицы, например `C:\TechTranscriber`.
3. Запустите `install_windows.bat` и дождитесь установки компонентов.
4. Запустите `run_windows.bat`.

При первом старте модели Whisper и распознавания голосов будут загружены на компьютер. После загрузки приложение может работать без интернета и без API-ключей.

## Как записать встречу

1. Выберите микрофон.
2. В поле «Звук приложений» выберите устройство, через которое слышна встреча.
3. Отметьте один или несколько тематических словарей. Кнопка «Все» включает весь набор.
4. Добавьте названия продуктов, проектов, участников и дополнительные термины — по одному в строке.
5. При необходимости нажмите «Скачать модель заранее», чтобы загрузка не начиналась во время встречи.
6. Нажмите «Начать запись».
7. Дважды щёлкните роль выбранной строки, чтобы изменить только её. Двойной щелчок по тексту открывает редактор реплики.
8. Нажмите «Остановить». Папка встречи откроется кнопкой «Открыть папку».

Важно: звук собеседников должен воспроизводиться через выбранное устройство. Наушники подходят — WASAPI копирует цифровой поток до его вывода в наушники.

## Модели

- `tiny` — самая быстрая, но хуже распознаёт термины;
- `small` — рекомендуемый баланс для обычного ноутбука;
- `medium` — точнее для русского и технической речи, желательно 16 ГБ ОЗУ;
- `large-v3` — максимальная точность, желательно NVIDIA GPU.

По умолчанию используется `small` и вычисления `int8` на CPU.

## Локальные словари

При первом запуске приложение создаёт тематические словари в папке:

`%USERPROFILE%\Documents\ТехСтенограмма\Словари`

Каждый словарь — обычный текстовый файл UTF-8, один термин в строке. В окне «Управление словарями» можно:

- открыть и отредактировать любой стандартный словарь;
- добавить или удалить термины;
- создать собственный словарь;
- удалить ненужный словарь;
- открыть папку и редактировать TXT-файлы другими программами.

Стандартные словари создаются только один раз. Удалённые пользователем файлы не восстанавливаются при следующем запуске. Для одной встречи можно активировать до 1500 уникальных терминов. Дополнительные термины встречи имеют наивысший приоритет.

## NVIDIA GPU

Обычная установка гарантированно работает на CPU. Для ускорения установите CUDA 12, cuBLAS и cuDNN 9, а также подходящую CUDA-сборку PyTorch. После этого перезапустите приложение. Если полный набор NVIDIA-компонентов недоступен, программа автоматически продолжит работу на CPU.

## Сборка EXE

На Windows запустите `build_windows.bat`. Результат появится в `dist\TechTranscriber`. Модели не встраиваются в EXE и загружаются при первом запуске.

## Конфиденциальность

Аудио и текст хранятся только в `%USERPROFILE%\Documents\ТехСтенограмма`. Облачные API не используются.
