# CoreTranscriber для Windows

Локальное приложение для записи встреч и транскрибации без платного API.

Что умеет:

- отдельно записывает микрофон и звук Windows-приложений;
- получает звук Dion, Express, Discord, Zoom и других программ через WASAPI loopback;
- распознаёт речь локально моделью Whisper;
- помечает микрофон как «Вы»;
- различает удалённых участников по голосовым отпечаткам;
- позволяет переименовать «Собеседник 1» в реальное имя или роль;
- использует словарь технических терминов;
- поставляется с тематическими TXT-словарями, включая эквайринг и банковский процессинг;
- позволяет выбирать один, несколько или все словари для встречи;
- позволяет создавать, изменять и удалять собственные словари;
- позволяет заранее скачать и подготовить живую и итоговую модели Whisper;
- показывает реальную дату и время начала каждой реплики;
- позволяет отдельно исправить роль и текст любой строки стенограммы;
- сохраняет WAV, TXT, Markdown, JSON, SRT и DOCX.

## Быстрый запуск на Windows 10/11

1. Установите Python 3.11 с сайта python.org. При установке включите **Add Python to PATH**.
2. Распакуйте проект в папку без кириллицы, например `C:\CoreTranscriber`.
3. Запустите `install_windows.bat` и дождитесь установки компонентов.
4. Запустите `run_windows.bat`.

При первом старте модели Whisper и распознавания голосов будут загружены на компьютер. После загрузки приложение может работать без интернета и без API-ключей.

## Как записать встречу

1. Выберите микрофон.
2. В поле «Звук приложений» выберите устройство, через которое слышна встреча.
3. Отметьте один или несколько тематических словарей. Кнопка «Все» включает весь набор.
4. Добавьте названия продуктов, проектов, участников и дополнительные термины — по одному в строке.
5. Нажмите «Скачать модели заранее», чтобы до встречи загрузить живую модель,
   модель итогового уточнения и проверить разделение голосов.
6. Нажмите «Начать запись».
7. Дважды щёлкните роль выбранной строки, чтобы изменить только её. Двойной щелчок по тексту открывает большой редактор с переносом строк и поиском по фразе.
8. Нажмите «Остановить». Папка встречи откроется кнопкой «Открыть папку».

Важно: звук собеседников должен воспроизводиться через выбранное устройство. Наушники подходят — WASAPI копирует цифровой поток до его вывода в наушники.

## Модели и производительность

- `tiny` — максимальная скорость, но ниже точность технических терминов;
- `base` — рекомендуется для живой записи на компьютере без NVIDIA CUDA;
- `small` — точнее, но требует более производительный процессор;
- `medium` — точная, но слишком медленная для быстрого уточнения на CPU;
- `turbo` — итоговая многоязычная модель с оптимизацией скорости;
- `large-v3` — максимальная точность, рекомендуется NVIDIA GPU.

По умолчанию используется `base`. На CPU приложение автоматически включает
`int8`, до восьми вычислительных потоков и быстрый поиск одного варианта. Это
оставляет ресурсы для захвата двух аудиопотоков, интерфейса и различения голосов.

Приложение сначала самостоятельно выделяет реплики по паузам. Повторный VAD
внутри Whisper отключён, поэтому уже подготовленный фрагмент не анализируется
второй раз и начала технических терминов реже обрезаются.

Если распознавание временно не успевает, аудио и речевые фрагменты не удаляются.
В строке состояния появится сообщение об отставании, а после снижения нагрузки
приложение обработает накопившуюся очередь. После остановки дождитесь сообщения
«Стенограмма и аудио сохранены».

По умолчанию включено быстрое уточнение после встречи моделью `small`. Две
сохранённые дорожки обрабатываются пакетами (`batch_size=8`, `beam_size=1`) с VAD,
поэтому тишина не прогоняется через Whisper. Это рекомендуемый профиль для Intel
Core Ultra 7 165U. Профиль `turbo` точнее, но на таком CPU может выйти за пределы
10 минут; `medium` оставлен как медленный режим совместимости.

Живой текст остаётся на диске как резерв до успешного завершения уточнения. Кнопка
«Пропустить уточнение» останавливает постобработку и позволяет быстрее перейти к
следующей встрече. Если модель не загрузится или завершится с ошибкой, исходная
стенограмма не заменяется. Предварительная загрузка готовит также итоговую модель
и модель голосов, чтобы после остановки не тратить время на их повторный запуск.

## Локальные словари

При первом запуске приложение создаёт тематические словари в папке:

`%USERPROFILE%\Documents\CoreTranscriber\Словари`

Каждый словарь — обычный текстовый файл UTF-8, один термин в строке. В окне «Управление словарями» можно:

- открыть и отредактировать любой стандартный словарь;
- добавить или удалить термины;
- создать собственный словарь;
- удалить ненужный словарь;
- открыть папку и редактировать TXT-файлы другими программами.

В версии 0.4.0 стандартные словари обновляются безопасно: неизменённые старые
файлы заменяются новой редакцией, а пользовательские термины сохраняются. Большой
словарь эквайринга разделён на шесть узких тем, чтобы ограниченный контекст Whisper
содержал действительно относящиеся к встрече термины. Дополнительные слова встречи
имеют наивысший приоритет, остальные равномерно выбираются из активных словарей.

## Встречи с несколькими участниками

Ваш микрофон помечается как «Вы». Голоса, поступающие через звук приложений,
кластеризуются отдельно и получают роли «Собеседник 1», «Собеседник 2» и далее.
Режим рассчитан в том числе на встречи с 2–5 участниками. Если несколько людей
говорят одновременно в одном аудиоканале, разделение может быть менее точным;
после встречи роль любой реплики можно исправить двойным щелчком.

## NVIDIA GPU

Обычная установка гарантированно работает на CPU. Для ускорения установите CUDA 12, cuBLAS и cuDNN 9, а также подходящую CUDA-сборку PyTorch. После этого перезапустите приложение. Если полный набор NVIDIA-компонентов недоступен, программа автоматически продолжит работу на CPU.

## Сборка EXE

На Windows запустите `build_windows.bat`. Результат появится в `dist\CoreTranscriber`. Модели не встраиваются в EXE и загружаются при первом запуске.

## Конфиденциальность

Аудио и текст хранятся только в `%USERPROFILE%\Documents\CoreTranscriber`. Облачные API не используются.
